# Harness icons

The bundled `anthropic.svg`, `opencode.svg`, and `cursor.svg` are Simple Icons brand marks, downloaded from the `simple-icons@16` package. The Simple Icons project is licensed CC0-1.0: <https://github.com/simple-icons/simple-icons/blob/develop/LICENSE.md>. Simple Icons asks users to follow each brand's current guidelines and legal disclaimer: <https://github.com/simple-icons/simple-icons/blob/develop/DISCLAIMER.md>.

The Claude mark is the Anthropic mark. Cursor Agent uses the Cursor mark. No harness-specific icon was available in Simple Icons for Codex, MUSE, Google Antigravity, or Zcode, so these use plain letter monograms; they are not presented as official logos. Automatic, unknown, and unrecognized values use neutral marks.

Sources: <https://cdn.jsdelivr.net/npm/simple-icons@16/icons/anthropic.svg>, <https://cdn.jsdelivr.net/npm/simple-icons@16/icons/opencode.svg>, <https://cdn.jsdelivr.net/npm/simple-icons@16/icons/cursor.svg>.
